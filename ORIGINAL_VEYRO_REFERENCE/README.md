# VEYRO Website V1

A scalable single-page studio website for VEYRO.

## Built now
Responsive design, visual identity, interactive cursor, magnetic buttons, scroll effects, tilt portfolio cards, service interactions, FAQ, founder/about content, portfolio concepts, process, playground foundation, project enquiry form, WhatsApp message generation, LocalStorage lead backup, SEO metadata, JSON-LD, robots.txt, sitemap.xml and social preview asset.

## Before public launch
- Replace `https://veyro.example/` with the real domain.
- Replace `WHATSAPP_NUMBER` in `index.html` with the real WhatsApp number.
- Confirm the real business email.
- Replace concept portfolio items with real or clearly labelled demo projects.
- Connect a real form endpoint / Google Apps Script for email + Sheets if required.
- Verify the domain in Google Search Console and submit `sitemap.xml`.
- Add real social profile URLs to JSON-LD when accounts exist.

## Important
The current form is intentionally frontend-only. It stores the latest lead locally and prepares a WhatsApp message. It does not claim to have a live CRM/backend until one is connected.
